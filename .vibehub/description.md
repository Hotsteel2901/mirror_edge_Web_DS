《镜之边缘 · WEB》是一款 Three.js 第一人称屋顶跑酷游戏：纯白都市、红色跑者视觉、连贯的跑酷动作，以及 City Protection 的屋顶追捕。

■ 跑酷
WASD 移动，Shift 冲刺，Space 跳跃 / 翻越 / 蹬墙跳，C 滑铲，E 滑索 / 攀爬管道。滑铲、翻越、蹬墙跑、攀爬、滑索、弹簧板、落地翻滚全部保留动量；持续冲刺会积累动量，极速逐渐提升。

■ 城市与任务
370 栋程序化楼体、187 个街区全城双向连通：135 座天桥、132 条滑索、76 块弹簧板、44 根攀爬管。按 J 打开任务板：递送 / 脱逃 / 侦查 / 追踪 4 类城市委托、6 章剧情行动、每日挑战；目标点有金色光柱与屏幕边缘标记。

■ 追捕与战斗
屋顶守卫会巡逻、起疑并交火。蹲伏可降低被发现距离；F 近战缴械会触发短暂的“反应时间”慢动作。生命值在脱战后自动回复，被击倒会回到最近安全点。

■ 金币与成长
四档金币（1 / 3 / 5 / 10 信用点），路线两门之间沿跑酷弧线撒有金币面包屑。信用点可在 K 技能商店升级 7 项技能（极速 / 体力 / 翻滚 / 磁吸 / 鹰眼 / 蹬墙 / 滑索）并解锁 6 套外观；30 项成就记录你的跑者生涯。

■ 计时挑战
8 条光门路线。按 T 开始计时挑战，最佳成绩会存为幽灵回放，并在每道门显示 Δ 时间差。

■ 光影
四套时段光照（清晨 / 正午 / 黄昏 / 阴天，L 切换）：纹素吸附阴影、天空 PMREM 环境反射、SSAO、半分辨率体积光、大气透视与 ACES 调色。

■ 其他
公共 MQTT 中继联机（Enter 聊天），同房间的跑者会以化身出现在城市中；Three.js r160 与全部后期模块已随包内置，无需联网加载外部库。建议桌面端 Chrome / Edge 全屏游玩。

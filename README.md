# 镜之边缘 · WEB —— 开放世界跑酷（Three.js）

第一人称屋顶跑酷游戏，全面对标《镜之边缘》原版：纯白都市 + 强原色点缀、红色跑者视觉路线、
连贯的移动系统（滑铲 / 翻越 / 蹬墙跑 / 攀爬 / 滑索 / 弹簧板 / 落地翻滚）、
**City Protection 屋顶追捕与缴械**、**城市委托与剧情行动**、**信用点 / 技能 / 外观经济**、
动态分层电子配乐，以及**无需自建服务器**的公共中继联机。

本轮重做新增：**全流程重写的光影管线**（纹素吸附阴影 / 天空 PMREM / 大气透视 / ACES 调色 /
四套时段光照）、**世界空间三平面 UV + 凹凸立面**、**追捕与近战**、**任务 / 商店 / 每日挑战**、
**街道生活与动态广告牌**、**9 首动态 BGM**。

### 移动端 / 触屏操作

自动识别手机、平板与二合一触屏设备（也可在主菜单「触屏操控」手动开关）：

- **左半屏浮动虚拟摇杆**：任意落指即居中，轻推慢走，**推到底自动冲刺**（亦可使用「⚡ 冲刺」胶囊锁定）。
- **右半屏自由划动**：转向视角；按住跳跃 / 滑铲 / 互动 / 缴械键的同时继续划动同样可平滑转视角。
- **右下角跑酷动作弧**：**跳**（翻越 / 蹬墙跳）、**铲/蹲**（高速滑铲 · 轻点切换蹲伏潜行）、**互动**（靠近滑索 / 攀爬管自动高亮）、**缴械**（靠近守卫高亮脉冲）、**180°**（急转掉头 / 蹬墙反跳）。
- **顶部快捷栏与自适应布局**：一键打开任务、技能、计时挑战、记录、聊天与暂停面板；完整适配横屏 / 竖屏、刘海屏安全区（Safe Area）与移动端自适应分辨率。

## 光影 · 大气 · 色彩

整套管线集中在 `src/graphics.js`，所有元素共享**同一个太阳方向**：

- **太阳与天空**：程序化天空着色器（高度渐变 + 米氏前向散射 + 太阳圆盘 + 4 阶 fbm 卷云），
  平行光、镜头辉光、体积光、大气透视使用完全一致的太阳方向与色温。
- **阴影**：按需重绘 + **光照空间纹素吸附**——阴影相机锚点被吸附到纹素整数倍网格，
  相机平移时阴影不再"蠕动"；4096 / 2048 / 1024 三档，PCFSoft 软阴影，法线偏移防漏光。
- **环境光**：用同一套天空材质烘 **PMREM 环境贴图**，玻璃幕墙与金属反射的是真实天光，
  而不是室内盒状环境。
- **大气透视**：半分辨率「视空间法线 + 线性深度」预通道，逐像素按视线方向把远处像素
  混向解析天空色，叠加太阳前向散射——远景有真实空气感，而不是一层白雾。
- **后期**：SSAO（多半径、距离淡出）→ 屏幕空间体积光（抖动 + 深度加权）→ Bloom →
  ACES 色调映射 → 分离色调 / 对比 / 饱和 / 暗角 / 胶片颗粒 / 速度色差。
- **时段光照**：清晨（长影）/ 正午（高光）/ 黄昏（暖阳）/ 阴天（柔光）四套预设一键切换，
  天空、太阳、雾密度、曝光、Bloom 同步改变，并重新烘焙环境贴图。
- **自适应分辨率**：高画质下按实测帧率在 0.7×–1.0× 之间缓慢调整渲染分辨率，带滞回。

## 玩法

### 连贯移动

- 落地保留全部水平动量；高冲击自动翻滚；**翻滚保留速度随「缓冲」技能提升**。
- 蹬墙跑冷却 + 连锁，墙面跳后仍能接住下一面墙；**「壁虎」技能延长蹬墙跑时长**。
- 冲刺 180° 急转保持速度；滑铲接跳跃可越过大缝隙。
- **动量系统**：持续冲刺（着地、有前进输入）会把极速从 11.6 提到约 12.5 m/s，停跑 / 撞墙衰减。
- 女儿墙 / 空调 / 通风管全部可翻越；楼身攀爬管 44 处，直接爬到塔顶。

### City Protection 追捕

- **16 名屋顶守卫**：巡逻 → 起疑（头顶警示）→ 交火 → 眩晕 / 缴械；视线走空间哈希射线，
  躲进女儿墙后即可切断视线。
- **蹲伏**把被发现距离从 52m 压到 24m；跑得越快越难被命中。
- 子弹为**命中扫描 + 曳光弹池**：命中同样做遮挡检测，不会穿墙打人；受击有 0.4s 无敌帧。
- **F 近战**：2.9m 内正面命中即缴械，触发 0.42s 反应时间（慢动作），附近守卫被惊动。
- 警报 14s 内会感染附近守卫；警报期间 BGM 自动切到 CHASE 曲目并拉满强度。
- 生命值 100，脱战 5s 后以 20/s 恢复；被击倒回到最近安全点。

### 城市委托 / 剧情 / 每日挑战

- **四种委托**：递送（取件 → 送达）、脱逃（触发警报 → 安全屋）、侦查（3 个信号点）、
  追踪（跟上无人机），全部限时，按距离与剩余时间结算信用点与经验。
- **剧情行动 6 章**：从"第一单"到"最后一段"，逐步提高距离、时限与警力压力；
  完成推进剧情并解锁下一章。
- **每日挑战**：按日期种子生成 3 个信号点，每天一次，奖励 320 信用点 + 260 经验。
- 任务目标点有金色冲天光柱 + 屏幕边缘金色菱形标记；HUD 显示阶段、距离与倒计时。

### 信用点经济

- **金币四档**：普通金币 1、银币 3、橙色路线币 5、青色数据芯片 10；全城 422 枚。
  路线两门之间自动撒"面包屑"金币，沿着跑酷弧线指引方向。
- 金币 / 委托 / 计时挑战产出 **¢ 信用点**，用于 **7 项技能 × 3 级** 与 **6 套外观**。
- **经验与等级**：拾取、委托、升级都给经验；等级提升额外奖励信用点，30 项成就记录里程碑。
- **技能**：疾风（极速）/ 长息（体力）/ 缓冲（翻滚保速）/ 磁吸（拾取半径）/ 鹰眼（跑者视觉）/
  壁虎（蹬墙时长）/ 索道（滑索速度）。

### FLOW 与计时挑战

- 连锁跑酷积攒 FLOW，倍率 ×1–×5；光门、缴械、委托、金币都会加速连锁。
- **8 条光门路线**，计时挑战 + 幽灵回放（压缩分段 + 15Hz 轨迹），每门显示 Δ 时间。
- 跑者视觉：红色 = 可跑酷动线，高速接近时动态高亮，远处目标有边缘标记。

## 地图设计

- **真实街道峡谷**：46m 街区网格，车行道 14–18m + 街区内部 3–5m 小巷；
  黄色虚线中线 / 斑马线 / 路缘石全部是**真实几何**。
- **370 栋楼 / 187 个街区**，三种原版立面（小窗网格 / 横向带窗 / 深色玻璃幕墙），
  **世界空间三平面 UV** 让任意尺寸楼体的窗格保持真实米制大小，凹凸贴图让窗洞在斜阳下有进深。
- **屋顶机械**：651 台冷却塔 / 空调、158 个屋顶楼梯间、水塔、通信塔、碟形天线、管道、
  女儿墙 + 栏杆、檐口压顶、晾衣棚、托盘、线缆盘。
- **街道生活**：83 张长椅、43 个垃圾桶、33 个消防栓、24 组红绿灯、20 座候车亭、
  40 组跨街灯串、517 处门洞与店面玻璃（带暖光自发光）、26 块大型广告牌、12 块**动态广告牌**
  （实时 canvas 动画）。
- **全城双向可达**：135 座天桥、132 条滑索、76 块弹簧板、11 面跑道墙、44 根攀爬管；
  相邻街区高差约束 ≤6m，187/187 个街区可达且能回到教学区。
- **地标**：The Shard（三层收分玻璃塔 + 停机坪 + 信号旗）、高架路、海湾码头（集装箱 / 龙门吊 /
  货轮 / 岸墙）、施工区、公园广场、三层雾中天际线、巡逻直升机、鸟群。
- **流浪金币**：路线面包屑 + 16 枚数据芯片分布在地标与最高楼顶。

## 性能

- 立面 / 屋顶 **InstancedMesh**，屋顶机械 / 天桥 / 集装箱 / 街道家具全部**几何合批**；
  典型视角约 **238 draw calls / 48 万三角形**。
- 碰撞体 3300+ **空间哈希网格**；射线与 AABB 查询只扫描邻近格子，零分配。
- 阴影按需重绘 + 纹素吸附；半分辨率预通道驱动 AO 与大气透视；HUD 零冗余写入；
  金币动画 20Hz 且只更新附近实例；成就检查 3Hz。
- 高画质自适应分辨率；低画质直出、关闭阴影与后期。
- `buildWorld` 分阶段让出主线程，加载条真实推进（约 1.4s 生成全城）。
